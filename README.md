🍽️ GastroFlow - SaaS de Gestión de Restaurantes y POS
Plataforma SaaS B2B multi-tenant para la gestión integral de restaurantes en Colombia. Desarrollado con una arquitectura moderna asíncrona, control de roles (RBAC), pantalla de cocina en tiempo real y facturación electrónica.

🚀 Características Principales
Control de Roles (RBAC): Paneles exclusivos para Admin, Mesero, Cajero y Cocinero.
Punto de Venta (POS): Toma de comandas, cálculo automático de IVA y totales.
Pantalla de Cocina (KDS): Sincronización en tiempo real mediante WebSockets.
Inventario Automático (Kardex): Descuento de stock automático al realizar una venta.
Facturación Electrónica (DIAN): Generación de CUFE criptográfico (SHA-384) e impresión de facturas en PDF.
Dashboard Dinámico: Métricas de ingresos y estados de pedidos en tiempo real con gráficos interactivos.

🛠️ Stack Tecnológico
Backend: Python, FastAPI (Asíncrono), SQLAlchemy, SQLite, JWT, WebSockets.Frontend: React, Vite, Tailwind CSS, React Router, Axios, Recharts, React Hot Toast.Arquitectura IA: Construido usando una Fábrica de Software con 7 Agentes de IA (CrewAI + DeepSeek).
